📐 Applet Interactivo GeoGebra HTML5

Integración de GeoGebra Web API en el Libro Descartes:
Este componente demuestra la incrustación fluida de escenas de GeoGebra HTML5 directamente dentro de la maquetación iCartesiLibri. Permite visualizar construcciones dinámicas de geometría de conjuntos, lógica proposicional y circuitos booleanos sin necesidad de plugins externos.
